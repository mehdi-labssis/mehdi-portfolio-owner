# Mehdi Labssis Portfolio

Independent Next.js portfolio owned and controlled by Mehdi Labssis.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Build for production

```bash
npm run build
npm start
```

## Where to edit

- Project information and links: `lib/projects.ts`
- Main pages: `app/`
- Shared navigation and cards: `components/`
- Images and the Maria Naqach demo: `public/`
- Global design and mobile layout: `app/globals.css`

This package contains no platform-specific authentication or hosting files. It can be deployed from your own GitHub repository to a hosting provider and connected to your own domain.
